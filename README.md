# QUERY RUSH（query-rush）

寿司職人ゲーム × SQL の高速クエリ組み立てアクション。

> ステータス: 仕様段階（コード未着手）。まず Issue #1 でMVP仕様を確定する。

## コンセプト

画面をポチポチしながら高速でSQLを組む。キーボード入力はゼロで、句チップをタップ／クリックしてクエリを組み立てる。チップを置くたびにテーブルがその場で絞り込まれてハイライトされるライブプレビューが、気持ちよさの本体。速さはマルチタスクではなく「データを読む判断の速さ」から作る。

## 遊び方（想定）

1. 注文票が提示される（例「売上が高い順に3件、返品は除く」）と、完成形の結果プレビューが見える
2. 下段の句チップの棚からチップを置いてクエリを組み立てる（置くたびに中段のテーブルへ即時反映）
3. 結果が注文と完全一致したら「提供」で次の注文へ
4. 不一致のまま確定したり不正な組み合わせにしたりするとミスでコンボが切れる

## MVP範囲

- 60秒スプリント（何件捌けるかのスコアアタック）のみ
- 注文は常時1件だけ、チップ配置は固定、同時表示チップは最大8枚
- DBは SQLite
- オンライン対戦・ランキングは対象外
