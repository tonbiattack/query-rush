# QUERY RUSH（query-rush）

UI Rush の骨格を SQL に移植した、4択で選ぶ認識ゲーム。

絞り込み前／後の小さなテーブルを見て、「どの `WHERE` でこうなったか」を固定4択チップで選ぶ。クエリを書く「生産」はさせない。認識と反応の速さで競い、速さはマルチタスクではなく「データを読む判断の速さ」から作る。

v1（2026-11-16）はチップを並べてクエリを組み立てる形式だったが、「勉強感・仕事感が強い」という指摘を受け、UI Rush / Type Rush の設計（見て選ぶ・間違いに寛容・解説は答えた後・スコアが残り時間と一緒に減る）を移植して v2 に書き換えた。経緯は [docs/SPEC.md](docs/SPEC.md) を参照。

## 遊び方

1. 上段に「絞り込み前」と「絞り込み後」のテーブルが出る（最大8行。消える行は打ち消し線、残る行はハイライト）
2. 下段の固定4択から「どの `WHERE` でこうなった？」に1タップで答える
3. 正誤表示中はタイマーが止まり、1行だけ解説が出る。正解でも不正解でも「次へ」で進む
4. 60秒タイムアタックで、スコア・正解数・最大ストリークを競う

### 操作

| 操作 | マウス／タッチ | キーボード |
| --- | --- | --- |
| 回答する | チップを押す | `1`〜`4` |
| 次へ進む | 「次へ」を押す | `Enter` |

## スコア

1問あたり最大300点。

- 基本 100点
- 速度ボーナス 0〜100点（残り時間に比例。「いま正解なら何点か」が画面に出る）
- ストリークボーナス 0〜100点（連続正解1つにつき+20）

不正解・時間切れは0点でストリークがリセットされる。ただしゲームは止まらない。

## 起動

Node.js 22.16 以上（`node:sqlite` の `statement.columns()` を使うため）。追加の依存パッケージはありません。

```powershell
npm start
# → http://127.0.0.1:4173
```

起動時に固定データから一時SQLiteデータベースを生成し、読み取り専用で開きます。ローカル専用の単一ゲームで、複数タブは同じ状態を共有します。

## 検証

```powershell
npm test                # ユニットテスト（エンジン／問題生成／コアループ／HTTP）
npm run check:questions # 問題データの検証
```

`check:questions` は全データセットの候補 `WHERE` を実際にSQLiteで実行し、各問題が次を満たすことを機械的に確かめます。

1. **一意性** — 4択のうち、正解の `WHERE` でだけ目標の絞り込み後テーブルになる
2. **惜しさ** — 不正解は同じ列・似た列名・近い演算子から選ばれている（ランダムなダミーなし）
3. **行数** — 表示は最大8行に収まる
4. **変化** — 行が実際に減っている
5. **コスト** — 100ms / 100行を超えない

問題データを追加・変更したら必ず通してください。

## 構成

```
src/
  config.js     調整用パラメーター（【】付きの名前でSPECから参照）
  data.js       テーブルとWHERE候補（罠を仕込んだ素材）
  engine.js     SQLite読み取り専用の実行基盤（WHERE検証・前後差分）
  questions.js  問題生成と一意性検証
  game.js       コアループ（4択／スコア減衰／ストリーク／60秒）
  server.js     静的配信とJSON API
public/         4択UI（HTML / CSS / クライアントJS）
scripts/        問題検証・スクリーンショット用
test/           ユニットテスト
```

## 設計上の絶対条件

`docs/SPEC.md` の3点を守っています。実装で崩さないでください。

1. **問題は常時1問だけ** — 同時処理の忙しさを入れない
2. **4択スロットの位置は固定** — 探す時間ではなく選ぶ時間で勝負させる
3. **テーブルは最大8行・選択肢は4つ** — 難化は行数や選択肢ではなくデータ側の罠で行う

## MVP範囲

- 60秒タイムアタック（正解数と合計スコア）が中心
- 問題は常時1問、4択スロットは固定、テーブル表示は最大8行
- スコアは基本100＋速度0〜100＋ストリーク0〜100（最大300／問）
- DBは SQLite（問題の生成・判定用、読み取り専用接続）
- オンライン対戦・ランキングは対象外

## MVP外（先送り）

- 苦手復習モード（間違えた罠だけを再出題）
- リバースモード（`WHERE` を見せて結果テーブルを選ぶ）
- JOIN・GROUP BY を扱う問題
- ウェーブ制サバイバル
